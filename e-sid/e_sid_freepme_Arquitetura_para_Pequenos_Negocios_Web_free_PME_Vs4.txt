0.  COLETA DE PARÂMETROS
================================================================================

Cada parâmetro listado nesta seção é OPCIONAL por padrão. A regra de
codificação é:

  • Parâmetro PREENCHIDO → substitui o placeholder correspondente em todos
    os templates que o referenciam.
  • Parâmetro NÃO PREENCHIDO / VAZIO → o placeholder é removido do código
    (tag, atributo ou bloco JSON-LD correspondente é omitido), e o template
    se ajusta sem quebrar.

Exceção: parâmetros marcados como [OBRIGATÓRIO] devem sempre ser preenchidos
— sem eles o entry point não funciona.

  0.1   SEU-USUARIO           [OBRIGATÓRIO]  Nome de usuário GitHub
  0.2   SEU-REPOSITORIO       [OBRIGATÓRIO]  Nome do repositório
  0.3   NOME_DA_EMPRESA       [OBRIGATÓRIO]  Nome fantasia / razão social
  0.4   CONTA_DO_NEGOCIO      [OBRIGATÓRIO]  Usuário do Instagram
  0.5   CIDADE                              Cidade do estabelecimento
  0.6   ESTADO                              UF do estabelecimento
  0.7   DDD_NUMERO                          Telefone WhatsApp (apenas dígitos)
  0.8   ANO                                 Ano de fundação
  0.9   HORARIO_DE_FUNCIONAMENTO            Ex.: "Seg–Sex 06:00–22:00, Sáb 07:00–18:00"
  0.10  LISTA_DE_SERVICOS                   Ex.: "Musculação, Natação, Hidroginástica"
  0.11  AREA_DE_ATUACAO                     Ex.: "academia de musculação e natação"
  0.12  DESCRICAO_CURTA                     Resumo para meta description e OG
  0.13  DESCRICAO_COMPLETA                  Texto completo para JSON-LD e llms-full.txt
  0.14  SEU_EMAIL                           E-mail de contato
  0.15  NOME_DO_AUTOR                       Nome do autor do projeto
  0.16  DATA_ATUAL                          Data ISO (YYYY-MM-DD)
  0.17  CNPJ_DO_NEGOCIO                     CNPJ com pontuação (XX.XXX.XXX/XXXX-XX)

  0.17-a  Inserção do CNPJ no privacidade.html

  O CNPJ NÃO é injetado via JavaScript. O modelo adota HTML estático sem
  dependência de runtime para páginas normativas.

  Fluxo:
    1. O template politicadeprivacidade.html no repositório compartilhado
       (menu/freepme/) contém o marcador
       {% if CNPJ_DO_NEGOCIO %}...{% endif %}.
    2. Ao copiar o template para a raiz do projeto como privacidade.html,
       o codificador substitui o CNPJ real ou remove a linha condicional
       inteira se o negócio não tiver CNPJ.
    3. Se CNPJ_DO_NEGOCIO estiver vazio, taxID é omitido do JSON-LD e a
       linha do CNPJ é omitida do HTML final.

  Justificativa: páginas de política de privacidade são noindex mas devem
  servir o conteúdo completo no HTML estático para conformidade LGPD (art.
  9º). Injeção via JS tornaria o dado indisponível em cenários sem
  JavaScript ou com falha de rede.

  0.18  REDE_SOCIAL (opcional)              Padrão: Instagram. Se outra rede,
                                            informar nome e URL completa.
  0.19  NATIVA_EXISTE                       Booleano. true se o projeto inclui
                                            nativa.html separado; false se
                                            index.html acumula ambas as funções.

================================================================================
1.  RESUMO EXECUTIVO
================================================================================

Arquitetura web de custo zero para dar presença digital estruturada a
pequenos negócios que operam majoritariamente via redes sociais. O modelo
entrega:

  • Página index.html completa (SEO/AEO/GEO/SXO/AIO) como entry point
    indexável
  • Click redirect para a rede social (Googlebot nunca clica — sem soft 404)
  • Timer fallback randômico 26-29s para humanos passivos
  • Arquivos normativos (robots.txt, sitemap.xml, llms.txt, .nojekyll,
    _config.yml)
  • Grafo JSON-LD bidirecional (LocalBusiness ↔ Person com worksOn)
  • LGPD completa para Brasil
  • Custo: R$ 0,00/mês (GitHub Pages + github.io)

Propósito: o site é o hub central de autoridade estruturada que alimenta a
presença nas redes sociais.

Componentes compartilhados (runtime — N projetos apontam para 1 fonte):
  https://edusidegum.github.io/menu/freepme/
    ├── politicadeprivacidade.html
    ├── bloco-cookies.html
    ├── bloco-ga4-gtm.html
    ├── bloco-incluir.js
    ├── bloco-protecao.js
    └── freepme.md

================================================================================

  https://SEU-USUARIO.github.io/SEU-REPOSITORIO/
  │
  ├── .nojekyll           ← OBRIGATÓRIO (vazio) — desativa Jekyll
  ├── _config.yml         ← Configuração de includes
  ├── index.html          ← ENTRY POINT: conteúdo completo, canonical limpo
  ├── [nativa.html]       ← OPCIONAL: página principal do negócio
  │                         (omitir quando index.html acumula ambas as
  │                          funções — ver parâmetro NATIVA_EXISTE)
  ├── privacidade.html    ← Política de Privacidade (LGPD)
  ├── robots.txt          ← Regras para todos os crawlers
  ├── llms.txt            ← Padrão para crawlers de IA
  ├── llms-full.txt       ← Conteúdo completo para LLMs (opcional)
  ├── sitemap.xml         ← Mapa do site
  └── assets/
      └── obras.png       ← 1200×1200px

Nota: nativa.html é OPCIONAL. Quando o entry point (index.html) já contém
o conteúdo completo do negócio — incluindo JSON-LD LocalBusiness, descrição
dos serviços e dados de contato — o arquivo separado pode ser omitido. O
sitemap, llms.txt e grafo JSON-LD refletem apenas os arquivos existentes
no repositório (ver parâmetro NATIVA_EXISTE).

7.  SCRIPT DE PROTEÇÃO — bloco-protecao.js
================================================================================

  Correção v2.3 mantida: bloqueios de Ctrl+S (salvar) e Ctrl+P (imprimir)
  removidos — não agregam segurança, prejudicam UX.

  /**
   * bloco-protecao.js  —  v2.3
   * Projeto: freepme — Templates Genéricos para Pequenos Negócios
   *
   * ⚠️ NÃO AFETA INDEXAÇÃO: Googlebot e crawlers de IA ignoram bloqueios
   *    de UI. Atua apenas no navegador do usuário humano.
   *
   * Ativado por: <meta name="protecao-copia" content="true">
   * Uso: Injetado automaticamente via bloco-incluir.js
   * Licença: MIT
   */
  (function(){
    'use strict';

    // Bloquear botão direito
    document.addEventListener('contextmenu', function(e){ e.preventDefault(); return false; });

    // Bloquear teclas de desenvolvedor
    document.addEventListener('keydown', function(e){
      if (e.keyCode === 123) { e.preventDefault(); return false; } // F12
      if (e.ctrlKey && e.shiftKey && (e.keyCode === 73 || e.keyCode === 74 || e.keyCode === 67)) { e.preventDefault(); return false; }
      if (e.ctrlKey && e.keyCode === 85) { e.preventDefault(); return false; } // Ctrl+U
    });

    // Bloquear Ctrl+A em não-inputs
    document.addEventListener('keydown', function(e){
      if (e.ctrlKey && e.keyCode === 65) {
        var tag = (e.target.tagName || '').toLowerCase();
        if (tag === 'input' || tag === 'textarea') return;
        e.preventDefault(); return false;
      }
    });

    // Bloquear arraste
    document.addEventListener('dragstart', function(e){ e.preventDefault(); return false; });

    // CSS: desabilitar seleção
    var style = document.createElement('style');
    style.textContent = 'body { -webkit-user-select: none; -moz-user-select: none; -ms-user-select: none; user-select: none; } input, textarea, [contenteditable] { -webkit-user-select: text; -moz-user-select: text; -ms-user-select: text; user-select: text; }';
    document.head.appendChild(style);
  })();

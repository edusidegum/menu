### 1. Resumo Executivo e Stack

Este documento consolida os templates finais e testados para o ecossistema multi-algoritmo 2026, parametrizados por [BASE_URL] e [BASE_PATH]. A versão 2026.2 (Vs4) introduz conformidade total com AEO, GEO (Generative + Geo-Context), SXO e AIO, incluindo otimizações específicas para Google AI Overviews e métricas de performance INP < 200ms.


Stack Técnica: GitHub Pages (estático), HTML semântico, Schema.org (LocalBusiness, Product, FAQ, Article, WebPage + mainEntity), NAP consistente, Core Web Vitals (INP < 200ms), Zero back-button hijack, JS mínimo no LCP, sem tracking desnecessário. llms.txt: não utilizado por decisão arquitetural.

### 3. Scripts de Sistema (Vibe Coding Ready)

#### 3.1 bloco-incluir.js (Rodapé e LGPD)
Injeta dinamicamente o footer padrão e o banner de cookies sem bloquear o LCP ou afetar o TBT.

```javascript
(function(){
  function init(){
    var basePath = window.__BASE_PATH__ || '/';
    var f = document.querySelector('footer.site-footer') || document.createElement('footer');
    f.className = 'site-footer';
    f.innerHTML = 'Desenvolvido por e-Sid Tech | Privacidade';
    if(!f.parentNode) document.body.appendChild(f);
  }
  if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', init);
  else init();
})();
```

#### 3.2 bloco-protecao.js (UX & A11y)
Proteção seletiva que respeita a preferência prefers-reduced-motion conforme WCAG 2.2 AA.

```javascript
(function(){
  if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) return;
  document.addEventListener('contextmenu', function(e){
    if (e.target.tagName==='IMG' || e.target.closest('figure')) e.preventDefault();
  });
  document.querySelectorAll('[data-protect]').forEach(el => el.style.userSelect = 'none');
})();
```

### 4. Estrutura de Diretórios e Governança de Crawlers

#### 4.1 robots.txt (Configuração Vs4)
Diretrizes explícitas para agentes de IA, permitindo indexação total para maximizar a presença em LLMs e Search Generative Experiences.

```text
User-agent: *
Allow: /
Disallow: [BASE_PATH]doc/
Disallow: [BASE_PATH]data/

User-agent: GPTBot
Allow: /
User-agent: Claude-Web
Allow: /
User-agent: Google-Extended
Allow: /
User-agent: PerplexityBot
Allow: /
```


Atenção: O arquivo llms.txt não é utilizado nesta arquitetura. A governança é centralizada via robots.txt para evitar redundância e conflitos de instrução.
